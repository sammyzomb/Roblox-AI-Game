# 首版 PvP 與訓練場範圍
日期：2026-09-30（Asia/Taipei）
來源：Product Owner 在 Technical Lead 專案的決策。狀態：設計已確認；不是程式完成或 Studio 驗收證據。
本文件優先於舊 GAME_DESIGN 中「PvE 為首版主要成長來源」的範圍描述。未提及的既有架構規則維持。

## 已定案
- 首版快速 PvP，劇情單人／組隊延後；對戰人數保留彈性，首版隊伍規模未定。
- 一张競技場、一種搶分模式，最多 3 分鐘；達目標分數提前結束，時間到高分方勝。
- 死亡給擊敗者一方 1 分；競技場結界約 3 秒復甦，HP/MP/體力恢復；職業裝備不變；已耗藥水不補回。出生保護在主動攻擊時解除。
- 首版劍士、法師、射手，開局選定且整局固定，三套預設配裝；長期自由配裝＋職業專精加成。
- 等級解鎖職業，不直接增加 PvP HP/傷害；競技實力用於配對。不同等級可組隊，雙方人數相同，預組隊優先匹配預組隊。
- 攻擊與輔助魔法皆存在。法師免詠唱，其他職業須詠唱；仍有 MP 消耗與冷卻。
- 首版一把魔導步槍。普通射擊用彈藥、有換彈、不耗 MP、不詠唱；附魔射擊另耗 MP，遵循職業詠唱規則。彈丸有飛行時間，可被障礙物或護盾阻擋。
- Robux 額外藥水於局外購買，入背包，下局攜帶；每局免費配給與付費庫存分開。
- 音效、槍械重量、換彈動作與聲音同步是重點品質要求，必須 Studio 實測。
- 參考：最強戰場（近戰回饋）、RIVALS（對戰流程與槍械）、Dueling Grounds（攻防）、World // Zero（職業與奇幻視覺）、Blade Ball（可讀性與造型展示）。參考不等於功能擴充。

## 首版訓練場（已確認）
小型訓練區，共用正式戰鬥核心與三套預設配裝。
1. 假人可練近戰、法術與槍械；顯示伺服器判定的傷害。
2. 一個定時攻擊練習來源，供格擋與護盾練習，不製作複雜 AI。
3. 補給重置可恢復 HP/MP/體力。訓練藥水為臨時庫存，不扣付費／永久庫存。
4. 不改競技評分、不提供可刷取 XP、貨幣或掉落。
5. 進入、死亡、重生、退出、斷線都不能把訓練數據寫回永久背包或 Loadout。
6. 正式發布後玩家可進入；目前 Studio-only TrainingDummyService 只算開發測試工具。
