+# Combat & Progression Core — Public API
+
+Owner: Claude (Primary Programmer) · Branch: `claude-dev` · Issue: #6
+PR: `feat: hybrid combat and progression core`
+
+One combat foundation for PvE and PvP. Weapon-agnostic, data-driven, server-authoritative.
+
+## 1. Layers
+
+```
+ReplicatedStorage/Shared/
+  ProgressionGates.luau        Level / milestone unlock checks (pure)
+  PlayerDataModel.luau         v2: Loadout, Milestones, Consumables (+ v1 migration)
+  Combat/
+    Types.luau                 Every data shape (WeaponDef, AttackDef, StatusEffectDef, ...)
+    DamageTypes.luau           Damage type registry + category (Physical / Magical / True)
+    Definitions.luau           Loads + validates + freezes all combat data
+    Data/Weapons.luau          Weapons and shields            <- balance lives here
+    Data/Armor.luau            Defensive equipment
+    Data/Consumables.luau      Defensive items / potions
+    Data/StatusEffects.luau    Buffs, debuffs, CC, DoT, defensive magic effects
+    CombatCore.luau            Rules engine (pure: no Roblox APIs, no clock)
+    DamageCalculator.luau      Damage math (pure)
+    StatusEffects.luau         Apply / stack / tick / cleanse / aggregate (pure)
+    Resources.luau             Stamina / mana / energy pools (pure)
+    Rulesets.luau              PvE / PvP targeting + normalization
+    Projectile.luau            Projectile simulation + sweep tests (pure, `vector`)
+ServerScriptService/Services/
+  CombatService.luau           Roblox glue: remotes, geometry, Humanoids, projectiles, NPCs
+  TrainingDummyService.luau    Studio-only PvE training dummies
+StarterPlayer/.../Controllers/CombatController.luau   Input -> CombatRequest
+StarterGui/UI/CombatHUD.client.luau                   Stamina / mana / barrier bars
+```
+
+Rule: **everything under `Shared/Combat` is pure** and covered by `luau tests/run.luau`.
+Roblox-specific code only lives in `CombatService`, the controller and the HUD.
+
+Pure modules require each other with Luau string requires (`require("./Types")`),
+which work identically in Roblox and in the Luau CLI.
+
+## 2. Data model (extension points)
+
+All shapes are in `Combat/Types.luau`. Summary:
+
+| Data | Key fields |
+|---|---|
+| `WeaponDef` | `Family` (free text), `Archetype` (Melee / RangedPhysical / Magic / Defense / Hybrid), `Slot` (MainHand / OffHand), `TwoHanded`, `Tier`, `Unlock`, `Attacks`, `Block?`, `Defense?` |
+| `AttackDef` | `Delivery` (Melee / Projectile / Area / Self), `Damage` (list of `{Type, Amount}`), `Range`, `Arc`, `Radius`, `Projectile`, `Windup`, `Recovery`, `Cooldown`, `Cost` (`{Pool, Amount}`), `Ammo`, `ArmorPenetration`, `Interruptible`, `RecoveryVulnerability`, `Blockable`, `OnHit`, `OnSelf`, `Heal` |
+| `ArmorDef` | `Slot` (Head / Body / Cloak / Talisman), `Defense` (`Armor`, `Resist` per damage type) |
+| `ConsumableDef` | `Cooldown`, `CooldownGroup`, `Heal`, `Restore`, `Apply` (statuses), `Cleanse` (tags) |
+| `StatusEffectDef` | `Duration`, `Stacking` (Refresh / Stack / Ignore), `Tags`, modifiers: `DamageTakenMultiplier`, `DamageDealtMultiplier`, `MoveSpeedMultiplier`, `Defense`, `Absorb`, `Reflect`, `Evasion`, `ImmuneToTags`, `Interrupts`, `PreventsActions`, `DamagePerSecond`, `HealPerSecond` |
+| `UnlockGate` | `Level?`, `Milestones?` (all present fields must pass) |
+| `Ruleset` | `Targeting`, `DamageMultiplier`, `ArchetypeMultipliers`, `LevelCap`, `ArmorCap`, `ResistCap`, `HealingMultiplier` |
+
+How to extend without touching core logic:
+
+- **New weapon** — add an entry to `Data/Weapons.luau`.
+- **New weapon class** (whips, scythes, approved firearms…) — new entries with a new `Family` and any combination of `Delivery`, `Damage`, `Ammo`, `Cost`. Proven by the test *"a brand-new weapon class works from data alone"*.
+- **New damage type** — one line in `DamageTypes.luau`.
+- **New resource** (Rage, Focus…) — add it to `Config.Combat.Pools`; reference it in `Cost`.
+- **New status / defensive spell** — entry in `Data/StatusEffects.luau`, then use it from `OnHit`, `OnSelf` or a consumable's `Apply`.
+- **New defensive item** — entry in `Data/Consumables.luau`.
+- **New mode / bracket** — add a ruleset in `Rulesets.luau`. Round logic (score, timer, respawn) belongs in a separate mode service that listens to `CombatService.Killed` / `Damaged`.
+
+`Definitions.get()` validates everything at boot and errors with a full list of problems.
+`Definitions.build(raw)` validates arbitrary data (tests, tools, future editor).
+
+## 3. Combat rules
+
+### Attack lifecycle (server)
+1. `beginAttack` — alive, not stunned/busy/blocking, cooldown, ammo, resources; pays costs; returns a plan with `ImpactAt`.
+2. Server waits `Windup`. `Interrupts` statuses (e.g. Stagger) cancel `Interruptible` windups.
+3. At impact the server measures geometry again (never trusts the client) and calls `checkReach` per target.
+4. `applyHit` per target (or `applySelf` for `Delivery = "Self"`).
+
+### Damage order
+`raw → level scale (capped by ruleset) → ruleset/archetype multiplier → armor (physical only, with penetration) → resist → damage-taken multipliers (statuses, heavy-attack recovery) → block → barrier → health → reflect (melee only) → on-hit statuses`
+
+- Armor: `reduction = armor / (armor + ArmorConstant)` — diminishing, never 100 %.
+- Resist is clamped to `[-0.5, ruleset.ResistCap]`.
+- DoT ignores armor, respects resist, can be absorbed by barriers.
+
+### Defense systems
+| System | Where |
+|---|---|
+| Armor / resist gear | `Data/Armor.luau`, weapon `Defense` |
+| Shields / blocking | weapon `Block` (frontal arc, % reduction, stamina per damage, guard break → Stagger) |
+| Defensive items | `Data/Consumables.luau` (heal, restore, barrier, resist, cleanse, escape) |
+| Defensive magic | `Delivery = "Self"` attacks with `OnSelf` (Barrier, FrostWard, Steadfast, Thornmail) |
+| Evasion | `Evasion` status modifier |
+| CC protection | `ImmuneToTags = { "CrowdControl" }` |
+
+### Balance levers
+- **Close-range power**: heavy melee has the highest per-hit damage (test-enforced) and pays with long `Windup` (interruptible), long `Recovery`, high stamina `Cost`, and `RecoveryVulnerability` (takes extra damage while recovering).
+- **Ranged physical**: lower burst, reach; `Ammo` + reload for crossbows/throwing.
+- **Magic**: `Mana` cost, cooldowns on the strongest spells, interruptible area casts.
+- **PvP normalization** (`Rulesets.PvP`): level scaling capped at 30, armor cap 40, resist cap 50 %, damage ×0.6, healing ×0.5. PvE progress helps, but cannot dominate.
+
+## 4. Progression gates
+
+```lua
+ProgressionGates.check(gate, profile) -> (boolean, reason?)
+ProgressionGates.unlocked(defs, profile) -> { id }       -- everything usable now
+ProgressionGates.newAtLevel(defs, level) -> { id }       -- "new unlocks" on level-up
+```
+`profile = { Level, Milestones = { [id] = true } }`. Gates are enforced by `CombatCore.equipWeapon`, `equipArmor` and `useConsumable` for players (NPCs skip them).
+Milestones are granted with `PlayerDataService:GrantMilestone(player, id)` (bosses, arena ranks…).
+
+## 5. CombatCore API (pure)
+
+```lua
+local engine = CombatCore.new(Definitions.get(), Config.Combat)
+engine:newCombatant(spec) -> Combatant
+engine:equipWeapon(c, id, profile?) / engine:equipArmor(c, id, profile?) / engine:unequip(c, slot)
+engine:defenseProfile(c) -> { Armor, Resist }
+engine:canAct(c, now)
+engine:beginAttack(c, slot, attackId, now) -> (Plan?, reason?)
+engine:isPlanValid(c, plan) / engine:finishAttack(c, plan) / engine:interrupt(c, now)
+engine:checkReach(attacker, target, attack, ruleset, { Distance, Angle? })
+engine:applyHit(attacker, target, weapon, attack, ruleset, now, { Random?, AngleFromTargetFacing? }) -> HitResult
+engine:applySelf(c, plan, ruleset?, now)
+engine:setBlocking(c, active, now)
+engine:useConsumable(c, id, now, profile?, ruleset?)
+engine:heal(c, amount, ruleset?)
+engine:tick(c, now, dt, ruleset) -> { Damage, Healed, Expired, Killed, KillerId }
+engine:revive(c, maxHealth?)
+```
+
+## 6. CombatService API (server)
+
+```lua
+CombatService:RegisterNPC(model, { Level, MaxHealth?, Team?, Weapons?, Armor?, BaseDefense?, RulesetId? })
+CombatService:Unregister(model)
+CombatService:GetCombatant(model) / CombatService:GetModel(combatantId)
+CombatService:RequestAttack(model, slot, attackId, aimPoint?)   -- same path for players and NPC AI
+CombatService:SetBlocking(model, active)
+CombatService:SetRuleset(player, "PvE" | "PvP" | ...)
+CombatService:SetTeam(model, team?)
+CombatService:Revive(model)                                      -- living combatants / round resets
+CombatService.AttackStarted / .Damaged / .Killed                 -- Signals for modes, rewards, quests, SFX
+```
+Tagging a Model (Humanoid + HumanoidRootPart) with `CombatNPC` registers it automatically; attributes `Level`, `MaxHealth`, `Weapon`, `Team`.
+
+### Network protocol
+`CombatRequest` (client → server), rate-limited and fully validated:
+
+| Action | Fields |
+|---|---|
+| `Attack` | `Slot` (MainHand/OffHand), `AttackId`, `Aim` (world point, optional) |
+| `Block` | `Active` (boolean) |
+| `UseItem` | `ItemId` (must be owned; count decremented) |
+| `Equip` | `Slot`, `ItemId` or `false` to unequip (gates checked, saved) |
+
+`CombatEvent` (server → clients), presentation only: `AttackStarted`, `Projectile`, `Area`, `Hit`, `Evaded`, `Killed`, `ItemUsed`, `Rejected` (to one player, with reason). Animation / VFX / SFX hook in `CombatController` here — see the SFX map from the creative team.
+
+Character attributes (replicated, 10 Hz): `Stamina`, `StaminaMax`, `Mana`, `ManaMax`, `Blocking`, `Barrier`.
+
+## 7. Security notes
+- The client sends intent only. Targets, damage, range, arcs, cooldowns, costs, ammo and unlocks are decided on the server.
+- Reach is re-measured at impact time with latency tolerances (`MeleeRangeTolerance`, `MeleeArcTolerance`).
+- Projectiles are simulated on the server from the attacker's real position and stopped by world geometry.
+- Aim points are validated (type, finite, max distance) and clamped to attack range.
+- Known limitation: character position and facing are client-owned physics in Roblox; this system bounds but cannot fully prevent movement exploits. A movement sanity check belongs in a future anti-cheat service.
+
+## 8. Ronin prototype
+The Ronin / odachi prototype maps onto this core as data: an `odachi` weapon entry (HeavyMelee family) plus a PvP arena mode service using `Rulesets.PvP` and the `Killed` signal. No katana-specific logic belongs in `Shared/Combat`.

+--!strict
+-- Weapon-agnostic combat rules shared by PvE and PvP.
+--
+-- Pure module: no Roblox APIs, no clocks, no randomness of its own. The server
+-- (CombatService) owns time, geometry and networking and calls into this.
+-- Every function reads only data fields (AttackDef, StatusEffectDef, ...);
+-- nothing here knows about specific weapons, families or modes.
+--
+-- Lifecycle of an attack:
+--   1. beginAttack   validate + pay costs, returns a plan with ImpactAt
+--   2. (server waits until ImpactAt; interrupts may cancel the plan)
+--   3. isPlanValid   is the plan still current?
+--   4. checkReach    is each candidate target valid and in reach? (geometry passed in)
+--   5. applyHit      damage + effects on each target, or applySelf for Self attacks
+--
+-- See docs/COMBAT_API.md for the full public API and extension points.
+
+local Types = require("./Types")
+local Definitions = require("./Definitions")
+local DamageCalculator = require("./DamageCalculator")
+local Resources = require("./Resources")
+local StatusEffects = require("./StatusEffects")
+local Rulesets = require("./Rulesets")
+local ProgressionGates = require("../ProgressionGates")
+
+type Combatant = Types.Combatant
+type WeaponDef = Types.WeaponDef
+type ArmorDef = Types.ArmorDef
+type AttackDef = Types.AttackDef
+type Ruleset = Types.Ruleset
+type HitResult = Types.HitResult
+type Slot = Types.Slot
+type StatusApplication = Types.StatusApplication
+type Defs = Definitions.Defs
+
+export type PoolSettings = { Max: number, Regen: number, RegenDelay: number }
+
+export type Settings = DamageCalculator.Settings & {
+	Pools: { [string]: PoolSettings },
+	MeleeRangeTolerance: number, -- extra studs allowed for latency
+	MeleeArcTolerance: number, -- extra degrees allowed for latency
+	BlockStartDelay: number, -- seconds before a raised guard counts (anti-spam)
+}
+
+export type CombatantSpec = {
+	Id: string,
+	Kind: Types.CombatantKind,
+	Team: string?,
+	Level: number,
+	MaxHealth: number,
+	Pools: { [string]: PoolSettings }?, -- defaults to Settings.Pools
+	BaseDefense: Types.DefenseProfile?,
+}
+
+export type Plan = {
+	Token: number,
+	Weapon: WeaponDef,
+	AttackId: string,
+	Attack: AttackDef,
+	StartedAt: number,
+	ImpactAt: number,
+}
+
+-- Geometry measured by the server at impact time.
+export type Reach = {
+	Distance: number, -- studs from attacker to target edge (Melee) or from impact point (Area)
+	Angle: number?, -- degrees between attacker facing and direction to target (Melee)
+}
+
+export type HitOptions = {
+	Random: (() -> number)?, -- returns [0,1); defaults to math.random
+	-- Degrees between the TARGET's facing and the direction to the attacker.
+	-- Needed for blocking; nil means "unknown" and the hit is not blockable.
+	AngleFromTargetFacing: number?,
+}
+
+export type TickResult = {
+	Damage: number,
+	Healed: number,
+	Expired: { string },
+	Killed: boolean,
+	KillerId: string?,
+}
+
+local CombatCore = {}
+CombatCore.__index = CombatCore
+
+local function defaultRandom(): number
+	return math.random()
+end
+
+export type Engine = typeof(setmetatable({} :: { Defs: Defs, Settings: Settings }, CombatCore))
+
+local function emptyResult(reason: string?): HitResult
+	return {
+		Hit = false,
+		Reason = reason,
+		Raw = 0,
+		Damage = 0,
+		Absorbed = 0,
+		Blocked = 0,
+		Reflected = 0,
+		Killed = false,
+		GuardBroken = false,
+		AppliedStatuses = {},
+	}
+end
+
+function CombatCore.new(defs: Defs, settings: Settings): Engine
+	return setmetatable({ Defs = defs, Settings = settings }, CombatCore)
+end
+
+---------------------------------------------------------------------------
+-- Combatants
+---------------------------------------------------------------------------
+
+function CombatCore.newCombatant(self: Engine, spec: CombatantSpec): Combatant
+	local pools = {}
+	for id, p in spec.Pools or self.Settings.Pools do
+		pools[id] = Resources.newPool(p.Max, p.Regen, p.RegenDelay)
+	end
+	return {
+		Id = spec.Id,
+		Kind = spec.Kind,
+		Team = spec.Team,
+		Level = spec.Level,
+		Alive = true,
+		Health = spec.MaxHealth,
+		MaxHealth = spec.MaxHealth,
+		Pools = pools,
+		Loadout = { Armor = {} },
+		BaseDefense = spec.BaseDefense or {},
+		Statuses = {},
+		Cooldowns = {},
+		Ammo = {},
+		BusyUntil = 0,
+		VulnerableFrom = 0,
+		VulnerableUntil = 0,
+		VulnerabilityMultiplier = 1,
+		Blocking = false,
+		BlockSince = 0,
+		Pending = nil,
+		NextToken = 1,
+	} :: any
+end
+
+-- Combined defense from base stats, equipped weapons/shields, armor and statuses.
+function CombatCore.defenseProfile(_self: Engine, c: Combatant): DamageCalculator.DefenseProfile
+	local armor = 0
+	local resist: { [string]: number } = {}
+	local function add(profile: Types.DefenseProfile?)
+		if profile == nil then
+			return
+		end
+		armor += profile.Armor or 0
+		if profile.Resist then
+			for damageType, value in profile.Resist do
+				resist[damageType] = (resist[damageType] or 0) + value
+			end
+		end
+	end
+	add(c.BaseDefense)
+	add(c.Loadout.MainHand and c.Loadout.MainHand.Defense)
+	add(c.Loadout.OffHand and c.Loadout.OffHand.Defense)
+	for _, piece in c.Loadout.Armor do
+		add(piece.Defense)
+	end
+	local mods = StatusEffects.modifiers(c)
+	armor += mods.Armor
+	for damageType, value in mods.Resist do
+		resist[damageType] = (resist[damageType] or 0) + value
+	end
+	return { Armor = armor, Resist = resist }
+end
+
+---------------------------------------------------------------------------
+-- Equipment and progression gates
+---------------------------------------------------------------------------
+
+-- Equips a weapon or shield by id. `profile` is the player's progression
+-- (nil for NPCs, which skip gates). Handles two-handed rules.
+function CombatCore.equipWeapon(self: Engine, c: Combatant, weaponId: string, profile: ProgressionGates.Profile?): (boolean, string?)
+	local def = self.Defs.Weapons[weaponId]
+	if def == nil then
+		return false, "UnknownItem"
+	end
+	if profile then
+		local ok, reason = ProgressionGates.check(def.Unlock, profile)
+		if not ok then
+			return false, reason
+		end
+	end
+	if c.Pending or c.Blocking then
+		return false, "Busy"
+	end
+	if def.Slot == "MainHand" then
+		c.Loadout.MainHand = def
+		if def.TwoHanded then
+			c.Loadout.OffHand = nil
+		end
+	else
+		if c.Loadout.MainHand and c.Loadout.MainHand.TwoHanded then
+			return false, "HandsFull"
+		end
+		c.Loadout.OffHand = def
+	end
+	return true, nil
+end
+
+function CombatCore.unequip(_self: Engine, c: Combatant, slot: Slot)
+	if slot == "MainHand" then
+		c.Loadout.MainHand = nil
+	elseif slot == "OffHand" then
+		c.Loadout.OffHand = nil
+		c.Blocking = false
+	else
+		for i = #c.Loadout.Armor, 1, -1 do
+			if c.Loadout.Armor[i].Slot == slot then
+				table.remove(c.Loadout.Armor, i)
+			end
+		end
+	end
+end
+
+-- Equips armor by id, replacing whatever is in the same slot.
+function CombatCore.equipArmor(self: Engine, c: Combatant, armorId: string, profile: ProgressionGates.Profile?): (boolean, string?)
+	local def = self.Defs.Armor[armorId]
+	if def == nil then
+		return false, "UnknownItem"
+	end
+	if profile then
+		local ok, reason = ProgressionGates.check(def.Unlock, profile)
+		if not ok then
+			return false, reason
+		end
+	end
+	self:unequip(c, def.Slot)
+	table.insert(c.Loadout.Armor, def)
+	return true, nil
+end

+---------------------------------------------------------------------------
+-- Attacks
+---------------------------------------------------------------------------
+
+local function weaponIn(c: Combatant, slot: Slot): WeaponDef?
+	if slot == "MainHand" then
+		return c.Loadout.MainHand
+	elseif slot == "OffHand" then
+		return c.Loadout.OffHand
+	end
+	return nil
+end
+
+local function cooldownKey(weapon: WeaponDef, attackId: string): string
+	return `{weapon.Id}:{attackId}`
+end
+
+function CombatCore.canAct(_self: Engine, c: Combatant, now: number): (boolean, string?)
+	if not c.Alive then
+		return false, "Dead"
+	end
+	if StatusEffects.modifiers(c).PreventsActions then
+		return false, "Stunned"
+	end
+	if c.Pending or now < c.BusyUntil then
+		return false, "Busy"
+	end
+	return true, nil
+end
+
+-- Validates and starts an attack: checks state, cooldown, ammo and resources,
+-- pays the costs and returns a plan. Nothing is paid if validation fails.
+function CombatCore.beginAttack(self: Engine, c: Combatant, slot: Slot, attackId: string, now: number): (Plan?, string?)
+	local weapon = weaponIn(c, slot)
+	if weapon == nil then
+		return nil, "NoWeapon"
+	end
+	local attack = weapon.Attacks[attackId]
+	if attack == nil then
+		return nil, "UnknownAttack"
+	end
+	local canAct, why = self:canAct(c, now)
+	if not canAct then
+		return nil, why
+	end
+	if c.Blocking then
+		return nil, "Blocking"
+	end
+
+	local key = cooldownKey(weapon, attackId)
+	if now < (c.Cooldowns[key] or 0) then
+		return nil, "Cooldown"
+	end
+
+	local ammo = nil
+	if attack.Ammo then
+		ammo = c.Ammo[key]
+		if ammo == nil then
+			ammo = { Loaded = attack.Ammo.Capacity, ReloadUntil = 0 }
+			c.Ammo[key] = ammo
+		end
+		if ammo.Loaded <= 0 then
+			if now < ammo.ReloadUntil then
+				return nil, "Reloading"
+			end
+			ammo.Loaded = attack.Ammo.Capacity
+		end
+	end
+
+	local cost = attack.Cost
+	if cost and not Resources.canSpend(c.Pools[cost.Pool], cost.Amount) then
+		return nil, `Not enough {cost.Pool}`
+	end
+
+	-- Everything validated: pay.
+	if cost then
+		Resources.spend(c.Pools[cost.Pool], cost.Amount, now)
+	end
+	if ammo and attack.Ammo then
+		ammo.Loaded -= 1
+		if ammo.Loaded <= 0 then
+			ammo.ReloadUntil = now + attack.Windup + attack.Ammo.ReloadTime
+		end
+	end
+	c.Cooldowns[key] = now + (attack.Cooldown or 0)
+
+	local impactAt = now + attack.Windup
+	c.BusyUntil = impactAt + attack.Recovery
+	if attack.RecoveryVulnerability and attack.RecoveryVulnerability > 1 then
+		c.VulnerableFrom = impactAt
+		c.VulnerableUntil = c.BusyUntil
+		c.VulnerabilityMultiplier = attack.RecoveryVulnerability
+	end
+
+	local token = c.NextToken
+	c.NextToken += 1
+	c.Pending = { Token = token, WeaponSlot = slot, AttackId = attackId, ImpactAt = impactAt }
+
+	return {
+		Token = token,
+		Weapon = weapon,
+		AttackId = attackId,
+		Attack = attack,
+		StartedAt = now,
+		ImpactAt = impactAt,
+	}, nil
+end
+
+-- True if `plan` is still the combatant's current attack (not interrupted, not dead).
+function CombatCore.isPlanValid(_self: Engine, c: Combatant, plan: Plan): boolean
+	return c.Alive and c.Pending ~= nil and c.Pending.Token == plan.Token
+end
+
+-- Call at impact time, after the hits (or the Self effect) are resolved.
+function CombatCore.finishAttack(_self: Engine, c: Combatant, plan: Plan)
+	if c.Pending and c.Pending.Token == plan.Token then
+		c.Pending = nil
+	end
+end
+
+-- Cancels a pending attack. Costs are not refunded; recovery is shortened.
+function CombatCore.interrupt(_self: Engine, c: Combatant, now: number): boolean
+	if c.Pending == nil then
+		return false
+	end
+	c.Pending = nil
+	c.BusyUntil = math.min(c.BusyUntil, now + 0.25)
+	c.VulnerableUntil = math.min(c.VulnerableUntil, now)
+	return true
+end
+
+-- Target + geometry validation at impact time.
+function CombatCore.checkReach(self: Engine, attacker: Combatant, target: Combatant, attack: AttackDef, ruleset: Ruleset, reach: Reach): (boolean, string?)
+	local ok, reason = Rulesets.canTarget(ruleset, attacker, target)
+	if not ok then
+		return false, reason
+	end
+	local s = self.Settings
+	if attack.Delivery == "Melee" then
+		if reach.Distance > (attack.Range or 0) + s.MeleeRangeTolerance then
+			return false, "OutOfRange"
+		end
+		local halfArc = (attack.Arc or 90) / 2 + s.MeleeArcTolerance
+		if reach.Angle == nil or reach.Angle > halfArc then
+			return false, "OutOfArc"
+		end
+	elseif attack.Delivery == "Area" then
+		if reach.Distance > (attack.Radius or 0) then
+			return false, "OutOfRange"
+		end
+	elseif attack.Delivery == "Self" then
+		return false, "SelfOnly"
+	end
+	-- Projectile reach is decided by the projectile simulation itself.
+	return true, nil
+end
+
+local function applyStatuses(self: Engine, target: Combatant, list: { StatusApplication }?, now: number, sourceId: string?, random: () -> number): { string }
+	local applied = {}
+	if list == nil then
+		return applied
+	end
+	for _, application in list do
+		local def = self.Defs.StatusEffects[application.Id]
+		if def and random() < (application.Chance or 1) then
+			if StatusEffects.apply(target, def, now, application.Duration, sourceId) then
+				table.insert(applied, def.Id)
+				if def.Interrupts and target.Pending then
+					local pendingWeapon = weaponIn(target, target.Pending.WeaponSlot)
+					local pendingAttack = pendingWeapon and pendingWeapon.Attacks[target.Pending.AttackId]
+					if pendingAttack and pendingAttack.Interruptible then
+						self:interrupt(target, now)
+					end
+				end
+			end
+		end
+	end
+	return applied
+end
+
+local function kill(c: Combatant)
+	c.Health = 0
+	c.Alive = false
+	c.Pending = nil
+	c.Blocking = false
+end
+
+-- Heals respecting the ruleset's healing multiplier. Returns amount healed.
+function CombatCore.heal(_self: Engine, c: Combatant, amount: number, ruleset: Ruleset?): number
+	if not c.Alive or amount <= 0 then
+		return 0
+	end
+	local scaled = amount * (if ruleset and ruleset.HealingMultiplier then ruleset.HealingMultiplier else 1)
+	local before = c.Health
+	c.Health = math.min(c.MaxHealth, c.Health + scaled)
+	return c.Health - before
+end

+-- Resolves one hit of `attack` from `attacker` on `target`. Call once per target
+-- after checkReach (or after a projectile collision). Mutates both combatants.
+function CombatCore.applyHit(self: Engine, attacker: Combatant, target: Combatant, weapon: WeaponDef, attack: AttackDef, ruleset: Ruleset, now: number, options: HitOptions?): HitResult
+	local opts: HitOptions = options or {}
+	local random = opts.Random or defaultRandom
+	local facingAngle = opts.AngleFromTargetFacing
+
+	local ok, reason = Rulesets.canTarget(ruleset, attacker, target)
+	if not ok then
+		return emptyResult(reason)
+	end
+
+	local targetMods = StatusEffects.modifiers(target)
+	if targetMods.Evasion > 0 and random() < targetMods.Evasion then
+		return emptyResult("Evaded")
+	end
+
+	local attackerMods = StatusEffects.modifiers(attacker)
+	local taken = targetMods.DamageTaken
+	if now >= target.VulnerableFrom and now < target.VulnerableUntil then
+		taken *= target.VulnerabilityMultiplier
+	end
+
+	local breakdown = DamageCalculator.compute({
+		Components = attack.Damage or {},
+		AttackerLevel = attacker.Level,
+		Archetype = weapon.Archetype,
+		ArmorPenetration = attack.ArmorPenetration,
+		DealtMultiplier = attackerMods.DamageDealt,
+		TakenMultiplier = taken,
+		Defense = self:defenseProfile(target),
+		Ruleset = ruleset,
+	}, self.Settings)
+
+	local result = emptyResult(nil)
+	result.Hit = true
+	result.Raw = breakdown.Raw
+	local remaining = breakdown.Final
+
+	-- Blocking: frontal, blockable hits only, after the guard has been up briefly.
+	local shield = target.Loadout.OffHand and target.Loadout.OffHand.Block
+		or target.Loadout.MainHand and target.Loadout.MainHand.Block
+	if
+		shield
+		and target.Blocking
+		and now - target.BlockSince >= self.Settings.BlockStartDelay
+		and attack.Blockable ~= false
+		and facingAngle ~= nil
+		and facingAngle <= shield.Arc / 2
+		and remaining > 0
+	then
+		local wanted = remaining * shield.Reduction
+		local staminaNeeded = wanted * shield.StaminaPerDamage
+		local stamina = target.Pools.Stamina
+		local drained = Resources.drain(stamina, staminaNeeded, now)
+		local blocked = if staminaNeeded > 0 then wanted * (drained / staminaNeeded) else wanted
+		if drained < staminaNeeded then
+			result.GuardBroken = true
+			target.Blocking = false
+		end
+		result.Blocked = blocked
+		remaining -= blocked
+	end
+
+	-- Barriers.
+	if remaining > 0 then
+		local absorbed = StatusEffects.consumeAbsorb(target, remaining)
+		result.Absorbed = absorbed
+		remaining -= absorbed
+	end
+
+	-- Health.
+	remaining = math.floor(remaining + 0.5)
+	result.Damage = math.min(remaining, target.Health)
+	target.Health -= result.Damage
+	if target.Health <= 0 then
+		kill(target)
+		result.Killed = true
+	end
+
+	-- Reflect only punishes close-range hits.
+	if attack.Delivery == "Melee" and targetMods.Reflect > 0 and result.Damage + result.Absorbed > 0 and attacker.Alive then
+		local reflected = math.floor((result.Damage + result.Absorbed) * targetMods.Reflect + 0.5)
+		reflected = math.min(reflected, attacker.Health)
+		attacker.Health -= reflected
+		result.Reflected = reflected
+		if attacker.Health <= 0 then
+			kill(attacker)
+		end
+	end
+
+	-- On-hit effects land unless the hit was fully stopped by a guard.
+	local fullyBlocked = result.Blocked > 0 and not result.GuardBroken and result.Damage == 0
+	if target.Alive and not fullyBlocked then
+		result.AppliedStatuses = applyStatuses(self, target, attack.OnHit, now, attacker.Id, random)
+	end
+	if result.GuardBroken and target.Alive then
+		local stagger = self.Defs.StatusEffects.Stagger
+		if stagger and StatusEffects.apply(target, stagger, now, nil, attacker.Id) then
+			table.insert(result.AppliedStatuses, "Stagger")
+		end
+	end
+
+	return result
+end
+
+-- Resolves the user-side part of an attack: OnSelf effects and Heal.
+-- For Delivery == "Self" this is the whole attack; other deliveries may also
+-- have OnSelf effects (e.g. a lunge that grants a short buff).
+function CombatCore.applySelf(self: Engine, c: Combatant, plan: Plan, ruleset: Ruleset?, now: number, random: (() -> number)?): { string }
+	if not c.Alive then
+		return {}
+	end
+	local applied = applyStatuses(self, c, plan.Attack.OnSelf, now, c.Id, random or defaultRandom)
+	if plan.Attack.Heal then
+		self:heal(c, plan.Attack.Heal, ruleset)
+	end
+	return applied
+end

+---------------------------------------------------------------------------
+-- Defense actions
+---------------------------------------------------------------------------
+
+function CombatCore.setBlocking(self: Engine, c: Combatant, active: boolean, now: number): (boolean, string?)
+	if not active then
+		c.Blocking = false
+		return true, nil
+	end
+	local shield = (c.Loadout.OffHand and c.Loadout.OffHand.Block) or (c.Loadout.MainHand and c.Loadout.MainHand.Block)
+	if shield == nil then
+		return false, "NoShield"
+	end
+	local canAct, why = self:canAct(c, now)
+	if not canAct then
+		return false, why
+	end
+	local stamina = c.Pools.Stamina
+	if stamina == nil or stamina.Current <= 0 then
+		return false, "Not enough Stamina"
+	end
+	if not c.Blocking then
+		c.Blocking = true
+		c.BlockSince = now
+	end
+	return true, nil
+end

+-- Uses a defensive item / consumable. `profile` gates it for players.
+function CombatCore.useConsumable(self: Engine, c: Combatant, itemId: string, now: number, profile: ProgressionGates.Profile?, ruleset: Ruleset?): (boolean, string?)
+	local def = self.Defs.Consumables[itemId]
+	if def == nil then
+		return false, "UnknownItem"
+	end
+	if not c.Alive then
+		return false, "Dead"
+	end
+	if profile then
+		local ok, reason = ProgressionGates.check(def.Unlock, profile)
+		if not ok then
+			return false, reason
+		end
+	end
+	if StatusEffects.modifiers(c).PreventsActions and not (def.Cleanse and table.find(def.Cleanse, "CrowdControl")) then
+		return false, "Stunned"
+	end
+	local key = `item:{def.CooldownGroup or def.Id}`
+	if now < (c.Cooldowns[key] or 0) then
+		return false, "Cooldown"
+	end
+	c.Cooldowns[key] = now + def.Cooldown
+
+	if def.Cleanse then
+		StatusEffects.cleanse(c, def.Cleanse)
+	end
+	if def.Heal then
+		self:heal(c, def.Heal, ruleset)
+	end
+	if def.Restore then
+		for _, restore in def.Restore do
+			Resources.restore(c.Pools[restore.Pool], restore.Amount)
+		end
+	end
+	applyStatuses(self, c, def.Apply, now, c.Id, defaultRandom)
+	return true, nil
+end
+
+---------------------------------------------------------------------------
+-- Per-frame upkeep
+---------------------------------------------------------------------------
+
+-- Regenerates pools (not while blocking), runs damage/heal over time, expires effects.
+function CombatCore.tick(self: Engine, c: Combatant, now: number, dt: number, ruleset: Ruleset): TickResult
+	local result: TickResult = { Damage = 0, Healed = 0, Expired = {}, Killed = false }
+	if not c.Alive then
+		return result
+	end
+	for id, pool in c.Pools do
+		if not (id == "Stamina" and c.Blocking) then
+			Resources.regen(pool, now, dt)
+		end
+	end
+
+	local ticks = StatusEffects.collectTicks(c, now)
+	if #ticks.Damage > 0 then
+		local defense = self:defenseProfile(c)
+		local total = 0
+		for _, component in ticks.Damage do
+			-- DoT ignores armor (it already got through) but respects resists.
+			local resist = DamageCalculator.resist(defense, component.Type, ruleset)
+			total += component.Amount * ruleset.DamageMultiplier * (1 - resist)
+			result.KillerId = component.SourceId
+		end
+		total = math.floor(total + 0.5)
+		local absorbed = StatusEffects.consumeAbsorb(c, total)
+		local damage = math.min(total - absorbed, c.Health)
+		c.Health -= damage
+		result.Damage = damage
+		if c.Health <= 0 then
+			kill(c)
+			result.Killed = true
+			return result
+		end
+	end
+	if ticks.Heal > 0 then
+		result.Healed = self:heal(c, ticks.Heal, ruleset)
+	end
+	result.Expired = StatusEffects.expire(c, now)
+	return result
+end
+
+-- Full reset for respawns / new rounds.
+function CombatCore.revive(_self: Engine, c: Combatant, maxHealth: number?)
+	c.MaxHealth = maxHealth or c.MaxHealth
+	c.Health = c.MaxHealth
+	c.Alive = true
+	c.Statuses = {}
+	c.Cooldowns = {}
+	c.Ammo = {}
+	c.Pending = nil
+	c.Blocking = false
+	c.BusyUntil = 0
+	c.VulnerableFrom = 0
+	c.VulnerableUntil = 0
+	for _, pool in c.Pools do
+		pool.Current = pool.Max
+	end
+end
+
+return CombatCore

+--!strict
+-- Pure damage math. No state is changed here; CombatCore applies the result.
+--
+--   raw        = sum(component.Amount) * levelScale * archetype/ruleset multipliers * dealtMultiplier
+--   per type   : Physical -> armor reduction then resist, Magical -> resist, True -> none
+--   armor      : reduction = armor / (armor + ArmorConstant)   (diminishing returns, never 100%)
+--   final      = mitigated * takenMultiplier (statuses, heavy-attack recovery vulnerability)
+--
+-- Block, barriers and reflect are applied later by CombatCore, in that order.
+
+local Types = require("./Types")
+local DamageTypes = require("./DamageTypes")
+
+type DamageComponent = Types.DamageComponent
+type Ruleset = Types.Ruleset
+
+export type Settings = {
+	ArmorConstant: number,
+	LevelDamageScaling: number, -- +x damage per level above 1
+	MinDamage: number, -- floor for any hit that dealt >0 raw damage
+}
+
+export type DefenseProfile = {
+	Armor: number,
+	Resist: { [string]: number },
+}
+
+export type Input = {
+	Components: { DamageComponent },
+	AttackerLevel: number,
+	Archetype: string?,
+	ArmorPenetration: number?,
+	DealtMultiplier: number?,
+	TakenMultiplier: number?,
+	Defense: DefenseProfile,
+	Ruleset: Ruleset,
+}
+
+export type Breakdown = {
+	Raw: number,
+	Final: number,
+	PerType: { [string]: number },
+}
+
+local DamageCalculator = {}
+
+function DamageCalculator.levelScale(level: number, ruleset: Ruleset, settings: Settings): number
+	local effective = if ruleset.LevelCap then math.min(level, ruleset.LevelCap) else level
+	return 1 + settings.LevelDamageScaling * (math.max(effective, 1) - 1)
+end
+
+function DamageCalculator.armorReduction(armor: number, penetration: number, ruleset: Ruleset, settings: Settings): number
+	local capped = if ruleset.ArmorCap then math.min(armor, ruleset.ArmorCap) else armor
+	local effective = math.max(0, capped * (1 - penetration))
+	return effective / (effective + settings.ArmorConstant)
+end
+
+function DamageCalculator.resist(defense: DefenseProfile, damageType: string, ruleset: Ruleset): number
+	local value = defense.Resist[damageType] or 0
+	-- Weakness is limited too, so a -100% resist can't double damage forever.
+	return math.clamp(value, -0.5, ruleset.ResistCap)
+end
+
+function DamageCalculator.compute(input: Input, settings: Settings): Breakdown
+	local ruleset = input.Ruleset
+	local scale = DamageCalculator.levelScale(input.AttackerLevel, ruleset, settings)
+		* ruleset.DamageMultiplier
+		* (input.DealtMultiplier or 1)
+	if input.Archetype and ruleset.ArchetypeMultipliers then
+		scale *= ruleset.ArchetypeMultipliers[input.Archetype] or 1
+	end
+
+	local armorReduction =
+		DamageCalculator.armorReduction(input.Defense.Armor, input.ArmorPenetration or 0, ruleset, settings)
+
+	local raw, final = 0, 0
+	local perType: { [string]: number } = {}
+	for _, component in input.Components do
+		local amount = component.Amount * scale
+		raw += amount
+		local category = DamageTypes.category(component.Type)
+		if category == "Physical" then
+			amount *= 1 - armorReduction
+		end
+		if category ~= "True" then
+			amount *= 1 - DamageCalculator.resist(input.Defense, component.Type, ruleset)
+		end
+		perType[component.Type] = (perType[component.Type] or 0) + amount
+		final += amount
+	end
+
+	final *= input.TakenMultiplier or 1
+	if raw > 0 then
+		final = math.max(settings.MinDamage, final)
+	end
+	return { Raw = raw, Final = final, PerType = perType }
+end
+
+return table.freeze(DamageCalculator)

+--!strict
+-- Registry of damage types.
+--
+-- Category decides which defense applies:
+--   Physical : reduced by Armor and by the type's own Resist
+--   Magical  : reduced only by Resist
+--   True     : never reduced (use sparingly: execute effects, falls)
+--
+-- Extension point: add a line to TYPES. Nothing else changes.
+
+export type Category = "Physical" | "Magical" | "True"
+
+local TYPES: { [string]: Category } = {
+	Slash = "Physical",
+	Pierce = "Physical",
+	Blunt = "Physical",
+	Fire = "Magical",
+	Frost = "Magical",
+	Lightning = "Magical",
+	Arcane = "Magical",
+	Poison = "Magical",
+	True = "True",
+}
+
+local DamageTypes = {}
+
+function DamageTypes.exists(id: string): boolean
+	return TYPES[id] ~= nil
+end
+
+function DamageTypes.category(id: string): Category
+	local category = TYPES[id]
+	assert(category, `unknown damage type "{id}"`)
+	return category :: Category
+end
+
+function DamageTypes.all(): { string }
+	local ids = {}
+	for id in TYPES do
+		table.insert(ids, id)
+	end
+	table.sort(ids)
+	return ids
+end
+
+return table.freeze(DamageTypes)

+		table.insert(errors, `{where}: attack must be a table`)

+	end

+			elseif not isNumber(component.Amount, 0) then
+				table.insert(errors, `{where}.Damage[{i}]: Amount must be >= 0`)
+			end
+		end
+	end

+		table.insert(errors, `{where}: Melee attacks need Range`)
+	elseif attack.Delivery == "Area" and (not isNumber(attack.Radius, 0) or not isNumber(attack.Range, 0)) then

+		end

+	end
+	if type(def.Family) ~= "string" then

+	if type(def) ~= "table" then
+		table.insert(errors, `{where}: must be a table`)
+		return
+	end
+	if not isNumber(def.Duration, 0) then
+		table.insert(errors, `{where}: Duration must be >= 0`)
+	end

+	end

+	end

+	end
+	if def.Reflect ~= nil and not isNumber(def.Reflect, 0, 1) then
+		table.insert(errors, `{where}: Reflect must be between 0 and 1`)
+	end
+	if def.DamagePerSecond ~= nil and not DamageTypes.exists(def.DamagePerSecond.Type) then
+		table.insert(errors, `{where}: unknown DamagePerSecond type`)
+	end
+	checkDefense(errors, where, def.Defense)
+end

+-- Copies each entry, stamps its Id from the table key, and deep-freezes it.
+local function deepFreeze(value: any): any
+	if type(value) ~= "table" or table.isfrozen(value) then
+		return value
+	end
+	for _, child in value do
+		deepFreeze(child)
+	end
+	return table.freeze(value)
+end

+local function stamp(source: { [string]: any }): { [string]: any }
+	local out: { [string]: any } = {}
+	for id, def in source do
+		local copy = table.clone(def)
+		copy.Id = id
+		out[id] = deepFreeze(copy)
+	end
+	return table.freeze(out)
+end

+		validateStatus(errors, id, def)
+	end

+		end
+	end

+	end
+	for id, def in raw.Consumables do
+		validateConsumable(errors, id, def, raw.StatusEffects)
+	end
+
+	if #errors > 0 then
+		table.sort(errors)
+		return nil, errors
+	end
+
+	return table.freeze({
+		Weapons = stamp(raw.Weapons),
+		Armor = stamp(raw.Armor),
+		Consumables = stamp(raw.Consumables),
+		StatusEffects = stamp(raw.StatusEffects),
+	}) :: any, errors
+end

+		return cached
+	end
+	local defs, errors = Definitions.build({

+	end

+	return defs

+--!strict
+-- Server-side projectile simulation math. Pure module using the `vector`
+-- library (vector values are Vector3 in Roblox), so it runs in unit tests.
+--
+-- The server owns every projectile: the client only sends an aim direction,
+-- the server spawns the projectile at the attacker's real position and steps
+-- it each frame, testing the swept segment against combatant hit spheres.
+
+local Types = require("./Types")
+
+type ProjectileSpec = Types.ProjectileSpec
+
+export type State = {
+	Position: vector,
+	Velocity: vector,
+	Travelled: number,
+	Spec: ProjectileSpec,
+	OwnerId: string,
+	HitIds: { [string]: boolean },
+	PierceLeft: number,
+	Done: boolean,
+}
+
+local Projectile = {}
+
+-- `direction` does not need to be normalized; a zero or non-finite direction is rejected.
+function Projectile.new(origin: vector, direction: vector, spec: ProjectileSpec, ownerId: string): State?
+	local length = vector.magnitude(direction)
+	if length ~= length or length < 1e-6 or length == math.huge then
+		return nil
+	end
+	return {
+		Position = origin,
+		Velocity = direction / length * spec.Speed,
+		Travelled = 0,
+		Spec = spec,
+		OwnerId = ownerId,
+		HitIds = {},
+		PierceLeft = spec.Pierce or 0,
+		Done = false,
+	}
+end
+
+-- Advances by dt. Returns the swept segment (from, to) for collision tests.
+function Projectile.step(p: State, dt: number): (vector, vector)
+	local from = p.Position
+	local gravity = p.Spec.Gravity or 0
+	if gravity ~= 0 then
+		p.Velocity -= vector.create(0, gravity * dt, 0)
+	end
+	local to = from + p.Velocity * dt
+	local segment = vector.magnitude(to - from)
+	if p.Travelled + segment >= p.Spec.MaxRange then
+		-- clip the final segment to the remaining range
+		local remaining = p.Spec.MaxRange - p.Travelled
+		if segment > 0 then
+			to = from + (to - from) * (remaining / segment)
+		end
+		p.Travelled = p.Spec.MaxRange
+		p.Done = true
+	else
+		p.Travelled += segment
+	end
+	p.Position = to
+	return from, to
+end
+
+-- Does segment a->b pass within `radius` of `center`? Returns the fraction
+-- along the segment (0..1) of the closest approach, used to order hits.
+function Projectile.sweepSphere(a: vector, b: vector, center: vector, radius: number): (boolean, number)
+	local ab = b - a
+	local lengthSq = vector.dot(ab, ab)
+	local t = 0
+	if lengthSq > 0 then
+		t = math.clamp(vector.dot(center - a, ab) / lengthSq, 0, 1)
+	end
+	local closest = a + ab * t
+	local offset = center - closest
+	return vector.dot(offset, offset) <= radius * radius, t
+end
+
+-- Records a hit. Returns true if the projectile should keep flying (pierce).
+function Projectile.registerHit(p: State, targetId: string): boolean
+	p.HitIds[targetId] = true
+	if p.PierceLeft > 0 then
+		p.PierceLeft -= 1
+		return true
+	end
+	p.Done = true
+	return false
+end
+
+return table.freeze(Projectile)

+--!strict
+-- Stamina / mana / energy pools. Pure module: callers pass the current time.
+--
+-- Pools are generic: any id in Config.Combat.Pools works ("Stamina", "Mana",
+-- later "Rage", "Focus"...). Attacks and items reference pools by id.
+
+local Types = require("./Types")
+
+type PoolState = Types.PoolState
+
+local Resources = {}
+
+function Resources.newPool(max: number, regen: number, regenDelay: number): PoolState
+	return { Current = max, Max = max, Regen = regen, RegenDelay = regenDelay, LastSpent = -math.huge }
+end
+
+function Resources.canSpend(pool: PoolState?, amount: number): boolean
+	if amount <= 0 then
+		return true
+	end
+	return pool ~= nil and pool.Current >= amount
+end
+
+-- Spends if affordable. Returns false (and spends nothing) otherwise.
+function Resources.spend(pool: PoolState?, amount: number, now: number): boolean
+	if amount <= 0 then
+		return true
+	end
+	if pool == nil or pool.Current < amount then
+		return false
+	end
+	pool.Current -= amount
+	pool.LastSpent = now
+	return true
+end
+
+-- Drains up to `amount`, returns how much was actually drained (block stamina).
+function Resources.drain(pool: PoolState?, amount: number, now: number): number
+	if pool == nil or amount <= 0 then
+		return 0
+	end
+	local drained = math.min(pool.Current, amount)
+	pool.Current -= drained
+	pool.LastSpent = now
+	return drained
+end
+
+function Resources.restore(pool: PoolState?, amount: number)
+	if pool == nil or amount <= 0 then
+		return
+	end
+	pool.Current = math.min(pool.Max, pool.Current + amount)
+end
+
+function Resources.regen(pool: PoolState, now: number, dt: number)
+	if now - pool.LastSpent < pool.RegenDelay then
+		return
+	end
+	pool.Current = math.min(pool.Max, pool.Current + pool.Regen * dt)
+end

+return table.freeze(Resources)

+--

+	PvE = {
+		Id = "PvE",
+		Targeting = {
+			PlayerVsPlayer = false,
+			PlayerVsNPC = true,
+			NPCVsPlayer = true,
+			NPCVsNPC = false,
+			FriendlyFire = false,
+		},
+		DamageMultiplier = 1,
+		ResistCap = 0.75,
+	},
+

+	-- but cannot dominate: levels above the bracket cap stop scaling damage,
+	-- armor and resists are capped, damage and healing are scaled down to
+	-- lengthen time-to-kill and keep skill relevant.
+	PvP = {
+		Id = "PvP",
+		Targeting = {
+			PlayerVsPlayer = true,
+			PlayerVsNPC = false,
+			NPCVsPlayer = false,
+			NPCVsNPC = false,
+			FriendlyFire = false,
+		},
+		DamageMultiplier = 0.6,
+		ArchetypeMultipliers = {},
+		LevelCap = 30,
+		ArmorCap = 40,
+		ResistCap = 0.5,
+		HealingMultiplier = 0.5,
+	},
+}

+	table.freeze(ruleset.Targeting)
+	if ruleset.ArchetypeMultipliers then
+		table.freeze(ruleset.ArchetypeMultipliers)
+	end
+	table.freeze(ruleset)
+end

+
+function Rulesets.get(id: string): Ruleset
+	local ruleset = RULESETS[id]
+	assert(ruleset, `unknown ruleset "{id}"`)
+	return ruleset

+	return RULESETS[id] ~= nil

+	if not target.Alive then
+		return false, "TargetDead"
+	end

+		return false, "SameTeam"

+	if attacker.Kind == "Player" then
+		allowed = if target.Kind == "Player" then t.PlayerVsPlayer else t.PlayerVsNPC
+	else
+		allowed = if target.Kind == "Player" then t.NPCVsPlayer else t.NPCVsNPC
+	end
+	if not allowed then
+		return false, "TargetNotAllowed"
+	end
+	return true, nil
+end

+--!strict
+-- Applies, stacks, ticks, cleanses and aggregates status effects on a combatant.
+-- Pure module: callers pass the current time. Effect behavior comes only from
+-- the StatusEffectDef fields, never from effect ids.
+
+local Types = require("./Types")
+
+type Combatant = Types.Combatant
+type StatusEffectDef = Types.StatusEffectDef
+type ActiveStatus = Types.ActiveStatus
+type DamageComponent = Types.DamageComponent
+
+export type Modifiers = {
+	DamageTaken: number,
+	DamageDealt: number,
+	MoveSpeed: number,
+	Armor: number,
+	Resist: { [string]: number },
+	Reflect: number,
+	Evasion: number,
+	PreventsActions: boolean,
+	ImmuneTags: { [string]: boolean },
+}

+export type Tick = {
+	Damage: { DamageComponent & { SourceId: string? } },
+	Heal: number,
+}
+
+local StatusEffects = {}
+
+local function hasTag(def: StatusEffectDef, tag: string): boolean
+	return def.Tags ~= nil and table.find(def.Tags, tag) ~= nil
+end
+
+function StatusEffects.isImmune(c: Combatant, def: StatusEffectDef): boolean
+	if def.Tags == nil then
+		return false
+	end
+	for _, active in c.Statuses do
+		local immune = active.Def.ImmuneToTags
+		if immune then
+			for _, tag in immune do
+				if hasTag(def, tag) then
+					return true
+				end
+			end
+		end
+	end
+	return false
+end
+
+-- Returns true if the effect was applied (or refreshed / stacked).
+function StatusEffects.apply(c: Combatant, def: StatusEffectDef, now: number, duration: number?, sourceId: string?): boolean
+	if not c.Alive or StatusEffects.isImmune(c, def) then
+		return false
+	end
+	local length = duration or def.Duration
+	local active = c.Statuses[def.Id]
+
+	if active == nil then
+		c.Statuses[def.Id] = {
+			Def = def,
+			Stacks = 1,
+			ExpiresAt = now + length,
+			SourceId = sourceId,
+			NextTickAt = if def.DamagePerSecond or def.HealPerSecond then now + 1 else nil,
+			Absorb = def.Absorb,
+		}
+		return true
+	end
+
+	if def.Stacking == "Ignore" then
+		return false
+	end
+	if def.Stacking == "Stack" then
+		active.Stacks = math.min(active.Stacks + 1, def.MaxStacks or 1)
+	end
+	active.ExpiresAt = math.max(active.ExpiresAt, now + length)
+	active.SourceId = sourceId or active.SourceId
+	if def.Absorb then
+		active.Absorb = def.Absorb -- refresh the barrier
+	end
+	return true
+end
+
+function StatusEffects.remove(c: Combatant, id: string)
+	c.Statuses[id] = nil
+end
+
+-- Removes every active effect having any of `tags`. Returns the removed ids.
+function StatusEffects.cleanse(c: Combatant, tags: { string }): { string }
+	local removed = {}
+	for id, active in c.Statuses do
+		for _, tag in tags do
+			if hasTag(active.Def, tag) then
+				table.insert(removed, id)
+				break
+			end
+		end
+	end
+	for _, id in removed do
+		c.Statuses[id] = nil
+	end
+	table.sort(removed)
+	return removed
+end
+
+-- Removes expired effects and effects whose barrier was used up.
+function StatusEffects.expire(c: Combatant, now: number): { string }
+	local expired = {}
+	for id, active in c.Statuses do
+		local barrierGone = active.Def.Absorb ~= nil and (active.Absorb or 0) <= 0
+		if now >= active.ExpiresAt or barrierGone then
+			table.insert(expired, id)
+		end
+	end
+	for _, id in expired do
+		c.Statuses[id] = nil
+	end
+	table.sort(expired)
+	return expired
+end
+
+-- Collects damage-over-time and heal-over-time due since the last tick.
+-- Ticks happen once per second per effect and scale with stacks.
+function StatusEffects.collectTicks(c: Combatant, now: number): Tick
+	local result: Tick = { Damage = {}, Heal = 0 }
+	for _, active in c.Statuses do
+		local nextTick = active.NextTickAt
+		while nextTick and nextTick <= now and nextTick <= active.ExpiresAt do
+			local dps = active.Def.DamagePerSecond
+			if dps then
+				table.insert(result.Damage, { Type = dps.Type, Amount = dps.Amount * active.Stacks, SourceId = active.SourceId })
+			end
+			if active.Def.HealPerSecond then
+				result.Heal += active.Def.HealPerSecond * active.Stacks
+			end
+			nextTick += 1
+		end
+		active.NextTickAt = nextTick
+	end
+	return result
+end
+
+-- Barrier hit points currently available.
+function StatusEffects.totalAbsorb(c: Combatant): number
+	local total = 0
+	for _, active in c.Statuses do
+		total += active.Absorb or 0
+	end
+	return total
+end
+
+-- Consumes up to `amount` from barriers (oldest expiry first). Returns amount absorbed.
+function StatusEffects.consumeAbsorb(c: Combatant, amount: number): number
+	local barriers: { ActiveStatus } = {}
+	for _, active in c.Statuses do
+		if (active.Absorb or 0) > 0 then
+			table.insert(barriers, active)
+		end
+	end
+	table.sort(barriers, function(a: ActiveStatus, b: ActiveStatus): boolean
+		return a.ExpiresAt < b.ExpiresAt
+	end)
+	local absorbed = 0
+	for _, active in barriers do
+		if amount <= 0 then
+			break
+		end
+		local take = math.min(active.Absorb :: number, amount)
+		active.Absorb = (active.Absorb :: number) - take
+		amount -= take
+		absorbed += take
+	end
+	return absorbed
+end
+
+-- Combined effect of every active status. Multipliers multiply (per stack),
+-- flat values add, evasion combines as independent chances, reflect adds (capped at 0.9).
+function StatusEffects.modifiers(c: Combatant): Modifiers
+	local mods: Modifiers = {
+		DamageTaken = 1,
+		DamageDealt = 1,
+		MoveSpeed = 1,
+		Armor = 0,
+		Resist = {},
+		Reflect = 0,
+		Evasion = 0,
+		PreventsActions = false,
+		ImmuneTags = {},
+	}
+	local notEvaded = 1
+	for _, active in c.Statuses do
+		local def, stacks = active.Def, active.Stacks
+		if def.DamageTakenMultiplier then
+			mods.DamageTaken *= def.DamageTakenMultiplier ^ stacks
+		end
+		if def.DamageDealtMultiplier then
+			mods.DamageDealt *= def.DamageDealtMultiplier ^ stacks
+		end
+		if def.MoveSpeedMultiplier then
+			mods.MoveSpeed *= def.MoveSpeedMultiplier
+		end
+		if def.Defense then
+			mods.Armor += (def.Defense.Armor or 0) * stacks
+			if def.Defense.Resist then
+				for damageType, value in def.Defense.Resist do
+					mods.Resist[damageType] = (mods.Resist[damageType] or 0) + value * stacks
+				end
+			end
+		end
+		if def.Reflect then
+			mods.Reflect += def.Reflect
+		end
+		if def.Evasion then
+			notEvaded *= 1 - def.Evasion
+		end
+		if def.PreventsActions then
+			mods.PreventsActions = true
+		end
+		if def.ImmuneToTags then
+			for _, tag in def.ImmuneToTags do
+				mods.ImmuneTags[tag] = true
+			end
+		end
+	end
+	mods.Reflect = math.min(mods.Reflect, 0.9)
+	mods.Evasion = 1 - notEvaded
+	return mods
+end
+
+return table.freeze(StatusEffects)

+function ProgressionGates.check(gate: Gate?, profile: Profile): (boolean, string?)

+		return false, `Requires level {gate.Level}`

+		for _, milestone in gate.Milestones do
+			if not profile.Milestones[milestone] then
+				return false, `Requires milestone {milestone}`
+			end
+		end
+	end
+	return true, nil
+end
+
+-- Ids of every entry in `defs` that `profile` has unlocked, sorted.
+function ProgressionGates.unlocked(defs: { [string]: Gated }, profile: Profile): { string }
+	local ids = {}
+	for id, def in defs do
+		if ProgressionGates.check(def.Unlock, profile) then
+			table.insert(ids, id)
+		end
+	end
+	table.sort(ids)
+	return ids
+end
+
+-- Ids whose level requirement is exactly `level` (for "new unlocks!" UI on level up).
+-- Milestone-only gates are not included.
+function ProgressionGates.newAtLevel(defs: { [string]: Gated }, level: number): { string }
+	local ids = {}
+	for id, def in defs do
+		if def.Unlock and def.Unlock.Level == level then
+			table.insert(ids, id)
+		end
+	end
+	table.sort(ids)
+	return ids
+end
+
+return table.freeze(ProgressionGates)

+local function applyHit(attacker: Entry, target: Entry, plan: Plan, ruleset: Ruleset, hitFrom: Vector3)

+		Kind = "Hit",
+		Target = target.Model,
+		Attacker = attacker.Model,

+		Blocked = math.floor(result.Blocked + 0.5),

+local function resolveMelee(attacker: Entry, plan: Plan, ruleset: Ruleset)
+	local origin = attacker.Root.Position
+	local look = attacker.Root.CFrame.LookVector
+	for _, target in entries do
+		if target ~= attacker and target.Combatant.Alive then
+			local offset = target.Root.Position - origin
+			local reach = { Distance = math.max(0, offset.Magnitude - HIT_RADIUS), Angle = flatAngle(look, offset) }
+			if engine:checkReach(attacker.Combatant, target.Combatant, plan.Attack, ruleset, reach) then
+				applyHit(attacker, target, plan, ruleset, origin)
+			end
+		end
+	end
+end

+local function clampAim(attacker: Entry, aim: Vector3?, range: number): Vector3
+	local origin = attacker.Root.Position
+	local point = aim or (origin + attacker.Root.CFrame.LookVector * range)
+	local offset = point - origin
+	if offset.Magnitude > range then
+		point = origin + offset.Unit * range
+	end
+	return point
+end

+local function resolveArea(attacker: Entry, plan: Plan, ruleset: Ruleset, aim: Vector3?)
+	local center = clampAim(attacker, aim, plan.Attack.Range or 0)
+	broadcast({ Kind = "Area", Attacker = attacker.Model, Center = center, Radius = plan.Attack.Radius })
+	for _, target in entries do
+		if target ~= attacker and target.Combatant.Alive then
+			local distance = math.max(0, (target.Root.Position - center).Magnitude - HIT_RADIUS)
+			if engine:checkReach(attacker.Combatant, target.Combatant, plan.Attack, ruleset, { Distance = distance }) then
+				applyHit(attacker, target, plan, ruleset, center)
+			end
+		end
+	end
+end

+local function launchProjectile(attacker: Entry, plan: Plan, ruleset: Ruleset, aim: Vector3?)
+	local spec = plan.Attack.Projectile
+	if spec == nil then
+		return
+	end
+	local root = attacker.Root
+	local origin = root.Position + root.CFrame.LookVector * 1.5 + Vector3.new(0, 1.5, 0)
+	local target = aim or (origin + root.CFrame.LookVector * spec.MaxRange)
+	-- Roblox's `vector` type is Vector3 at runtime; the casts only satisfy the type checker.
+	local state = Projectile.new(origin :: any, (target - origin) :: any, spec, attacker.Combatant.Id)
+	if state == nil then
+		return
+	end
+	table.insert(projectiles, { State = state, Owner = attacker, Plan = plan, Ruleset = ruleset })
+	broadcast({
+		Kind = "Projectile",
+		Attacker = attacker.Model,
+		Weapon = plan.Weapon.Id,
+		Attack = plan.AttackId,
+		Origin = origin,
+		Velocity = state.Velocity :: any,
+		Gravity = spec.Gravity or 0,
+		MaxRange = spec.MaxRange,
+	})
+end

+local function resolve(attacker: Entry, plan: Plan, aim: Vector3?)
+	if entries[attacker.Model] ~= attacker or not engine:isPlanValid(attacker.Combatant, plan) then
+		return -- interrupted, dead or unregistered during the windup
+	end
+	local ruleset = Rulesets.get(attacker.RulesetId)
+	local delivery = plan.Attack.Delivery
+	if delivery == "Melee" then
+		resolveMelee(attacker, plan, ruleset)
+	elseif delivery == "Area" then
+		resolveArea(attacker, plan, ruleset, aim)
+	elseif delivery == "Projectile" then
+		launchProjectile(attacker, plan, ruleset, aim)
+	end
+	if plan.Attack.OnSelf or plan.Attack.Heal then
+		engine:applySelf(attacker.Combatant, plan, ruleset, now())
+	end
+	engine:finishAttack(attacker.Combatant, plan)
+	sync(attacker, now())
+end
+
+local function stepProjectiles(dt: number)
+	if #projectiles == 0 then
+		return
+	end
+	local exclude: { Instance } = {}
+	for model in entries do
+		table.insert(exclude, model)
+	end
+	local params = RaycastParams.new()
+	params.FilterType = Enum.RaycastFilterType.Exclude
+	params.FilterDescendantsInstances = exclude
+
+	for i = #projectiles, 1, -1 do
+		local p = projectiles[i]
+		local state = p.State
+		local fromV, toV = Projectile.step(state, dt)
+		local from: Vector3, to: Vector3 = (fromV :: any), (toV :: any)
+		local segment = to - from
+
+		-- World geometry stops projectiles.
+		local limit = 1
+		local wall = Workspace:Raycast(from, segment, params)
+		if wall and segment.Magnitude > 0 then
+			limit = (wall.Position - from).Magnitude / segment.Magnitude
+		end
+
+		-- Combatants hit along the segment, nearest first.
+		local candidates = {}
+		for _, target in entries do
+			local id = target.Combatant.Id
+			if id ~= state.OwnerId and target.Combatant.Alive and not state.HitIds[id] then
+				local hit, t = Projectile.sweepSphere(fromV, toV, target.Root.Position :: any, HIT_RADIUS + state.Spec.Radius)
+				if hit and t <= limit and Rulesets.canTarget(p.Ruleset, p.Owner.Combatant, target.Combatant) then
+					table.insert(candidates, { Entry = target, T = t })
+				end
+			end
+		end
+		table.sort(candidates, function(a, b)
+			return a.T < b.T
+		end)
+		for _, candidate in candidates do
+			applyHit(p.Owner, candidate.Entry, p.Plan, p.Ruleset, from)
+			if not Projectile.registerHit(state, candidate.Entry.Combatant.Id) then
+				break
+			end
+		end
+
+		if wall then
+			state.Done = true
+		end
+		if state.Done then
+			table.remove(projectiles, i)
+		end
+	end
+end

+		return
+	end

+		engine:unequip(c, slot :: Types.Slot)
+	else

+		local ok, why

+			if def == nil or def.Slot ~= slot then
+				return reject(entry, "WrongSlot")
+			end
+			ok, why = engine:equipWeapon(c, itemId, profile)
+		else
+			local def = defs.Armor[itemId]
+			if def == nil or def.Slot ~= slot then
+				return reject(entry, "WrongSlot")
+			end
+			ok, why = engine:equipArmor(c, itemId, profile)
+		end
+		if not ok then
+			return reject(entry, why)
+		end
+	end

+	playerData:Update(player, function(d)
+		local loadout: any = {
+			MainHand = c.Loadout.MainHand and c.Loadout.MainHand.Id,
+			OffHand = c.Loadout.OffHand and c.Loadout.OffHand.Id,
+		}

+		end

+	end)

+local function onRequest(player: Player, request: unknown)
+	if type(request) ~= "table" then
+		return
+	end
+	if not limiter:allow(player.UserId, now()) then
+		return
+	end
+	local entry = byPlayer[player]
+	if entry == nil or not entry.Combatant.Alive then
+		return
+	end
+	local r = request :: any
+	local action = r.Action
+
+	if action == "Attack" then
+		if not HAND_SLOTS[r.Slot] or not isId(r.AttackId) then
+			return
+		end
+		local aim: Vector3? = nil
+		if r.Aim ~= nil then
+			if not isFiniteVector(r.Aim) or (r.Aim - entry.Root.Position).Magnitude > MAX_AIM_DISTANCE then
+				return
+			end
+			aim = r.Aim
+		end
+		local ok, why = CombatService:RequestAttack(entry.Model, r.Slot, r.AttackId, aim)
+		if not ok then
+			reject(entry, why)
+		end
+	elseif action == "Block" then
+		if type(r.Active) ~= "boolean" then
+			return
+		end
+		local ok, why = CombatService:SetBlocking(entry.Model, r.Active)
+		if not ok then
+			reject(entry, why)
+		end
+	elseif action == "UseItem" then
+		if isId(r.ItemId) then
+			onUseItem(entry, player, r.ItemId)
+		end
+	elseif action == "Equip" then
+		if type(r.Slot) == "string" and (r.ItemId == false or isId(r.ItemId)) then
+			onEquip(entry, player, r.Slot, r.ItemId)
+		end
+	end
+end
+

+---------------------------------------------------------------------------

+

+	for _, player in Players:GetPlayers() do
+		if playerData:Get(player) then
+			onPlayerDataLoaded(player)
+		end
+	end
+
+	-- Level ups raise max health; gear gates are re-checked on the next equip.
+	playerData.Changed:Connect(function(player: Player, data)
+		local entry = byPlayer[player]
+		if entry and entry.Combatant.Level ~= data.Level then
+			local c = entry.Combatant
+			local ratio = c.Health / c.MaxHealth
+			c.Level = data.Level
+			c.MaxHealth = maxHealthFor(data.Level)
+			c.Health = math.max(1, math.floor(c.MaxHealth * ratio + 0.5))
+		end
+	end)
+
+	Players.PlayerRemoving:Connect(function(player)
+		local entry = byPlayer[player]
+		if entry then
+			self:Unregister(entry.Model)
+		end
+		playerRuleset[player] = nil
+		limiter:clear(player.UserId)
+	end)
+
+	CollectionService:GetInstanceAddedSignal(NPC_TAG):Connect(registerTagged)
+	CollectionService:GetInstanceRemovedSignal(NPC_TAG):Connect(function(instance)
+		if instance:IsA("Model") then
+			self:Unregister(instance)
+		end
+	end)
+	for _, instance in CollectionService:GetTagged(NPC_TAG) do
+		registerTagged(instance)
+	end
+
+	RunService.Heartbeat:Connect(function(dt)
+		local t = now()
+		for _, entry in entries do
+			local c = entry.Combatant
+			if c.Alive then
+				local tick = engine:tick(c, t, dt, Rulesets.get(entry.RulesetId))
+				if tick.Damage > 0 then
+					broadcast({ Kind = "Hit", Target = entry.Model, Damage = tick.Damage, OverTime = true })
+				end
+				if tick.Killed then
+					onKilled(entry, tick.KillerId and byId[tick.KillerId] or nil)
+				end
+				sync(entry, t)
+			end
+		end
+		stepProjectiles(dt)
+	end)
+end
+
+return CombatService

+-- Sends combat intent to the server. Weapon-agnostic: the actions below are
+-- mapped to whatever attacks the equipped weapons define in data.
+--
+--   Action         Keyboard/Mouse   Gamepad   Touch
+--   Attack         Left click       R2        on-screen button
+--   Skill          Q                R1        on-screen button
+--   Off-hand       R                L1        on-screen button
+--   Block (hold)   F                L2        on-screen button
+--   Potion         1                DPad Up   on-screen button
+--
+-- "Attack" uses the main-hand attack named "Primary" (or the first by name),
+-- "Skill" uses the next main-hand attack, "Off-hand" the first off-hand attack.
+-- The server validates everything; this only avoids pointless requests.
+
+local ContextActionService = game:GetService("ContextActionService")
+local Players = game:GetService("Players")
+local ReplicatedStorage = game:GetService("ReplicatedStorage")
+local UserInputService = game:GetService("UserInputService")
+local Workspace = game:GetService("Workspace")

+local AIM_DISTANCE = 300
+
+-- Attack ids of a weapon: "Primary" first, then alphabetical.
+local function attackOrder(weaponId: string?): { string }
+	local weapon = weaponId and defs.Weapons[weaponId]
+	if not weapon then
+		return {}
+	end
+	local ids = {}
+	for id in weapon.Attacks do
+		table.insert(ids, id)
+	end
+	table.sort(ids, function(a, b)
+		if a == "Primary" or b == "Primary" then
+			return a == "Primary"
+		end
+		return a < b
+	end)
+	return ids
+end
+
+-- World point under the mouse / screen center (touch and gamepad).
+local function aimPoint(): Vector3?
+	local camera = Workspace.CurrentCamera
+	if camera == nil then
+		return nil
+	end
+	local screen: Vector2
+	if UserInputService.MouseEnabled and not UserInputService.TouchEnabled then
+		screen = UserInputService:GetMouseLocation()
+		local ray = camera:ViewportPointToRay(screen.X, screen.Y)
+		return CombatController.raycast(ray.Origin, ray.Direction * AIM_DISTANCE)
+	end
+	local ray = camera:ViewportPointToRay(camera.ViewportSize.X / 2, camera.ViewportSize.Y / 2)
+	return CombatController.raycast(ray.Origin, ray.Direction * AIM_DISTANCE)
+end

+	local result = Workspace:Raycast(origin, direction, params)
